# Ativos ilustrativos TAL

As quatro imagens foram geradas para este protótipo com a ferramenta de imagens, a partir de direção de arte própria. Não são fotos dos produtos ou da oficina da TAL e não confirmam modelos em estoque.

- `scooter-ivory.webp`: conceito urbano branco pérola, fundo transparente.
- `scooter-ivory-mobile.webp`: a mesma ilustração em 960×640 para telas menores; sem mudança de desenho ou animação.
- `scooter-graphite.webp`: conceito de conforto preto grafite, fundo transparente.
- `scooter-silver.webp`: conceito versátil prata acetinado, fundo transparente.
- `assistance.webp`: ilustração fotográfica de inspeção de freio em ambiente de oficina.

Os arquivos PNG de origem foram preservados no ambiente em `/workspace/generated_images`. A conversão para WebP alterou apenas a codificação para entrega na web. O conjunto WebP tem aproximadamente 700 KB.

O logo usado na interface é um SVG provisório reconstruído a partir das fotos enviadas pelo usuário. O arquivo vetorial oficial e a tipografia oficial ainda precisam ser fornecidos para validação fiel da marca. As fontes locais Manrope e Archivo Black vêm dos respectivos pacotes Fontsource, com licença SIL Open Font License.

Os estudos do catálogo novo e suas miniaturas têm [registro separado](studies/README.md).
